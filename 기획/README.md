## 문서 관리

- 현재 기준은 담당 설계 문서에 한 번 기록하고 다른 문서에서 링크한다.
- 호출 형식과 타입은 구현된 공용 코드, 동작 의미와 승인 상태는 계약 명세를 함께 기준으로 삼는다. 둘이 다르면 총괄에게 보고한다.
- 제안, 승인된 기준, 구현 완료, 검증 완료를 구분한다. 문서에 적혔다고 구현된 것은 아니다.
- 작업·변경·오류는 공통 ID로 연결한다. 역할별 중복 일지를 만들지 않는다.
- 중요한 결정은 이유와 영향을 보존하고, 바뀐 결정은 이전 기록을 지우는 대신 새 결정에서 연결한다.
- 아직 합의하지 않은 게임 규칙과 세부 시스템 문서는 작성하지 않는다. `02_게임_설계/시스템/`은 추후 기획 명세를 위한 위치다.

현재는 문서화 단계이며 실제 게임 프로젝트와 환경 고정 설정은 아직 생성하지 않았다.
